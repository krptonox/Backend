# Backend

- `EjsProject/`: EJS-based sample projects with views and partials.
- `Express/`: Express.js examples, routes, and app setup files.
- `File-Handling/`: File read, write, copy, and text handling demos.
- `Http_server/`: Simple HTTP server scripts and log output files.
- `Modules/`: CommonJS module practice files and hashing examples.
- `structure/`: HTML structure examples, components, and card assets.
- `URL/`: URL handling examples for old and new server flows.
- `package.json`: Root project metadata and shared package configuration.
